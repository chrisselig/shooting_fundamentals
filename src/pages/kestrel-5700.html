02

What It Actually Measures

  • Wind speed & direction
  • Temperature, humidity, heat index
  • Pressure, and pressure/density altitude

All of that feeds Applied Ballistics' solver on the device itself, so it can output an actual firing solution (drop and wind hold), not just raw weather numbers you'd have to plug into something else.

Neither Kestrel nor Applied Ballistics markets this toward rimfire specifically It's pitched generically at long-range shooters. The framing on this page — that wind and muzzle velocity accuracy matter a lot for 22LR — is this site's own editorial take, not a manufacturer claim.
03

Muzzle Velocity Calibration

Worth Doing

The 5700 Elite line includes a built-in MV Cal Guide, which lets you true up your rifle's actual MV without owning a separate chronograph — by working backward from where your bullet actually lands.

This matters more for 22LR than it might seem. Rimfire drop is steep and its trajectory is disproportionately sensitive to small MV errors compared to a fast centerfire round — a wrong MV assumption throws your dope off at exactly the distances NRL22 targets sit at. Run the calibration guide, and re-run it if you change ammo lots.

  1. Enter your baseline data first. Gun, bullet, scope, and a starting MV guess (off the box, or a rough estimate) all need to be entered before the guide has anything to calibrate against.
  2. Open the guide. From the Gun screen, go to the MV submenu and select Cal MV.
  3. Let it suggest a distance. The Kestrel proposes a calibration distance — roughly where your bullet is predicted to slow to about Mach 1.2, which is the range window where MV error shows up most clearly in drop. For best results, shoot somewhere around 85–100% of the suggested distance.
  4. Shoot at that distance using the drop value the Kestrel displays as your hold.
  5. Enter what actually happened, not a correction. If your hold predicted 5.25 mils but your actual impact was 5.5 mils low, you set Drop to 5.5 — the true observed value, not the difference between the two.
  6. Apply it. The Kestrel recalculates MV automatically from that entry and shows you the adjustment it made.
An MV-Temp table overrides this If you've built a temperature-paired MV table for your rifle (MV logged at several different temperatures), the Kestrel uses that table instead of a single calibrated MV — running Cal MV won't change anything while a table is active. You'd edit the table entries directly instead.

Using It At The Line

Conceptual Workflow

Exact menu wording changes between firmware versions, so this is the shape of the workflow rather than a tap-by-tap guide — check your unit's current menu if a step doesn't match.

  1. Power on and let it settle for a real-time reading rather than reading it the instant you turn it on.
  2. Hold it so the wind vane/impeller is actually exposed to the wind, not blocked by your body or the barricade.
  3. In Weather Mode, watch the wind reading over the same 1–2 minutes you'd use to build a bracket by eye (see Reading Conditions → Wind Bracket) — the meter is a faster, more precise version of that same lull/gust observation, not a replacement for watching the conditions.
  4. Switch to Ballistics Mode and confirm the active gun profile is the one you're actually shooting — the Manage Guns screen is where you swap profiles if you shoot more than one rifle.
  5. Toggle CAPTURE to start continuous wind capture if conditions are gusty, so the solver is working off a live read rather than one snapshot.
  6. With a profile set up (see AB Quantum), the Ballistics screen gives you a hold directly from the current reading.
05

Which App Does What

Two different apps pair with the device over Bluetooth, for two different jobs — easy to mix up when you're new to it.

  • Kestrel LiNK Ballistics (KLB) — firmware updates and device settings, like renaming the unit.
  • AB Quantum — your rifle/ammo profile and the actual firing solution, pulling live weather from the Kestrel once paired.

A USB LiNK dongle is also sold separately if you'd rather tether to a computer than pair over Bluetooth.

Pairing, Step By Step

  1. On the Kestrel: Options → Bluetooth → On.
  2. Set the connection mode to PC/Mobile — the device's status should change to Available.
  3. Open AB Quantum's Devices screen on your phone; it scans automatically and lists the Kestrel once it's in range and Available.
  4. Tap the device to connect — status flips to Connected on the Kestrel and Active in the app.
  5. If you've set a Bluetooth privacy PIN on the Kestrel, you'll be prompted for it once during this step.
Keep it within about 100ft, line of sight That's the Kestrel's rated Bluetooth range. Steps 1–2 (Kestrel side) are sourced from Kestrel's own manual; step 3–4 (AB Quantum side) reflect the app's generic device-pairing flow, which is shared with other paired accessories like chronographs — the overall shape should hold for a Kestrel, but treat the exact on-screen wording as approximate.
